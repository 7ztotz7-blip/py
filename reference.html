คู่มือคำสั่ง Python

รวบรวมคำศัพท์ ฟังก์ชัน และโครงสร้างภาษา Python ที่ใช้ในหลักสูตร เพื่อการทบทวน

1. คำสั่งพื้นฐาน (Basics)

print()

ใช้สำหรับแสดงผลข้อความหรือค่าของตัวแปรออกทางหน้าจอ

print("Hello, World!") print("คะแนน:", 100)
input()

ใช้รับข้อมูลจากผู้ใช้งานผ่านคีย์บอร์ด โดยค่าที่รับมาจะเป็นข้อความ (String) เสมอ

name = input("กรอกชื่อ: ") print(name)
# (คอมเมนต์)

ใช้เขียนคำอธิบายโค้ด โปรแกรมจะข้ามบรรทัดที่ขึ้นต้นด้วย # ไปโดยไม่ประมวลผล

# นี่คือคอมเมนต์ x = 10 # กำหนดค่า 10 ให้ x

2. ชนิดข้อมูลและการแปลงค่า (Data Types & Casting)

int()

แปลงข้อมูลให้เป็นจำนวนเต็ม (Integer) เช่น แปลงข้อความ "10" เป็นตัวเลข 10

age = int("25") total = age + 5
float()

แปลงข้อมูลให้เป็นเลขทศนิยม (Float)

price = float("99.50")
str()

แปลงข้อมูลให้เป็นข้อความ (String) เพื่อนำไปต่อกับข้อความอื่น

score = 95 msg = "ได้คะแนน " + str(score)
type()

ตรวจสอบชนิดของข้อมูลในตัวแปร

print(type(10)) # <class 'int'>

3. เงื่อนไข (Conditionals)

if, elif, else

ใช้ตรวจสอบเงื่อนไข หากเงื่อนไขเป็นจริง (True) จะทำคำสั่งในบล็อกนั้น

if score >= 80: print("Grade A") elif score >= 50: print("Pass") else: print("Fail")
and, or, not

ตัวดำเนินการทางตรรกศาสตร์ ใช้เชื่อมเงื่อนไขหลายอันเข้าด้วยกัน

if age >= 18 and has_ticket: print("เข้าได้")

4. การวนซ้ำ (Loops)

for loop

ใช้ทำซ้ำตามจำนวนรอบที่แน่นอน หรือวนลูปผ่านข้อมูลในลิสต์

for i in range(3): print("รอบที่", i)
while loop

ใช้ทำซ้ำไปเรื่อยๆ ตราบใดที่เงื่อนไขยังคงเป็นจริง (True)

hp = 3 while hp > 0: print("ยังไม่ตาย") hp = hp - 1
range()

สร้างลำดับตัวเลข มักใช้คู่กับ for loop (เริ่มจาก 0 และไม่รวมตัวสุดท้าย)

# ได้ 1, 2, 3, 4 for n in range(1, 5): print(n)

5. โครงสร้างข้อมูล (Data Structures)

List [...]

ตัวแปรชุดที่เก็บข้อมูลได้หลายค่า เรียงลำดับ และแก้ไขค่าได้

fruits = ["apple", "banana"] fruits.append("mango") print(fruits[0]) # apple
len()

ใช้นับจำนวนสมาชิกในลิสต์ หรือความยาวของข้อความ

count = len([10, 20, 30]) print(count) # 3
Dictionary {...}

เก็บข้อมูลเป็นคู่คีย์และค่า (Key-Value) ค้นหาข้อมูลด้วยคีย์แทนตัวเลข

user = {"name": "John", "age": 20} print(user["name"])

6. ฟังก์ชัน (Functions)

def

ใช้สร้างฟังก์ชันของตัวเอง เพื่อจัดกลุ่มโค้ดและนำกลับมาใช้ซ้ำ

def greet(name): print(f"Hi, {name}!") greet("Alice")
return

ส่งค่าผลลัพธ์ออกจากฟังก์ชันกลับไปให้ผู้ที่เรียกใช้

def add(a, b): return a + b total = add(5, 10)

ไม่พบคำสั่งที่ค้นหา

ลองค้นหาด้วยคำอื่น เช่น 'print', 'loop', 'list'
